# sunzi-command（将道·地形·情报）· 使用说明

> 从《孙子兵法》（九变、行军、地形、九地、火攻、用间六篇）蒸馏出的"带队与情报"技能。它管的是**你成了那个带队的人**之后：怎么判环境、怎么带人、怎么摸对手、怎么控住代价。

## 这个技能解决什么

计划定了、局面开了，但真正的难点变成"人"和"环境"：团队散、地不熟、对手在想什么全靠猜。核心一句话：**带人靠机制不靠个人勇武；最危险的不是敌人，是自己的性格死穴、环境误判和靠侥幸代替准备。**

## 怎么触发（用户会说的自然语言）

- "新环境/新市场，我该按什么打法？"
- "团队散漫，怎么拧成一股绳？"
- "这个人/这个将领有什么弱点可被利用？"
- "怎么搞清楚对手到底在想什么？"
- "是不是该放弃这个、违抗那个上级指令？"

## 典型用法

1. **判地形**：先给环境分类（通畅/易进难出/必争/险窄/势均），不同类打法不同；组织失利先查管理。
2. **临机权变**：常规该做不一定做、该听不一定听；每决策同时算利与害。
3. **识人破绽**：别把优点当绝对好——必死/必生/易怒/爱洁/爱民过强即成死穴。
4. **带队伍**：关爱+纪律并行，只爱不令=骄子不可用；规模不是答案。
5. **摸底牌**：靠可见信号反推对手状态；把情报当最高杠杆投入，重点经营反向信息节点。
6. **控代价**：不合算不动、不靠侥幸、绝不为情绪开战。

## 什么时候不要用

- 你方团队不齐心、信息被截留时，前提（知己）先崩。
- 对手也精通虚实且你被反间渗透，情报会反噬。
- 非对抗目标硬用，会过度设防。

## 与另外两个技能的关系

- **sunzi-strategy** 管"该不该打"；**sunzi-adapt** 管"打起来怎么变"；本技能管"带队、进环境、摸情报、控代价"。
- 完整打一场：先 strategy 算清，再 adapt 应变，最后 command 落地带人。
