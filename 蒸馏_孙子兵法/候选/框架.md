# 框架候选（主料）

## F1 · 五事七计庙算框架
- 结构：先经五事（道、天、地、将、法），再校七计（主孰有道／将孰有能／天地孰得／法令孰行／兵众孰强／士卒孰练／赏罚孰明），据此索其情、推胜负。
- 适用场景：任何"该不该做、能不能赢"的事前判断，把模糊的"我觉得行"变成可逐项打分的对照表。
- 原文位置：block_01 / 始计第一
- 原文摘录：故经之以五事，校之以七计，而索其情……吾以此知胜负矣。

## F2 · 全胜梯度框架
- 结构：取胜分四级梯度——全国＞破国＞全军＞破军……；手段分四级——上兵伐谋＞伐交＞伐兵＞攻城（攻城为不得已）。
- 适用场景：解决冲突时优先选"不破坏地拿下"，把目标从"赢"升级为"完整取得"。
- 原文位置：block_01 / 谋攻第三
- 原文摘录：是故百战百胜，非善之善者也；不战而屈人之兵，善之善者也。

## F3 · 兵力对比决策框架
- 结构：按兵力对比给动作——十则围之、五则攻之、倍则分之、敌则能战之、少则能守之、不若则能避之。
- 适用场景：资源/实力不对等时，决定是压上、纠缠、防守还是回避，而不是"硬上"。
- 原文位置：block_01 / 谋攻第三
- 原文摘录：故用兵之法，十则围之，五则攻之，倍则分之，敌则能战之，少则能守之，不若则能避之。

## F4 · 先为不可胜 / 形胜框架
- 结构：先把自己练到"不可胜"（守不足、藏于九地），再等敌可胜（攻有余、动于九天）；用度→量→数→称→胜五级把实力量化成胜算；胜兵先胜而后求战。
- 适用场景：竞争开始前先确保自己不输，再图赢；用客观指标替代"我觉得能行"。
- 原文位置：block_02 / 军形第四
- 原文摘录：昔之善战者，先为不可胜，以待敌之可胜……胜兵先胜而后求战，败兵先战而后求胜。

## F5 · 奇正相生框架
- 结构：以正合、以奇胜；正=正面牵制，奇=侧翼奇兵；奇正之变如循环无端，不可胜穷。
- 适用场景：任何"明面动作+暗手"的组合设计，避免只用一招、被对手看死。
- 原文位置：block_02 / 兵势第五
- 原文摘录：凡战者，以正合，以奇胜……奇正相生，如循环之无端，孰能穷之哉？

## F6 · 任势框架
- 结构：求之于势、不责于人；营造险节（势如彍弩、节如发机），择人而任势；如转圆石于千仞之山，势能自己做功。
- 适用场景：与其苛责个人发挥，不如设计让"对的人在对的位置上被态势推着走"的环境。
- 原文位置：block_02 / 兵势第五
- 原文摘录：故善战者，求之于势，不责于人，故能择人而任势。

## F7 · 虚实主动权框架
- 结构：致人而不致于人；我专敌分（形人而我无形）→ 以众击寡；避实击虚；因敌变化而取胜者谓之神。
- 适用场景：把对手调度到被动，自己集中、对手分散；永远打对方虚弱处，不打其准备好处。
- 原文位置：block_02 / 虚实第六
- 原文摘录：故善战者，致人而不致于人……兵之胜，避实而击虚……能因敌变化而取胜者，谓之神。

## F8 · 以迂为直 / 军争框架
- 结构：军争之难在以迂为直、以患为利（后人发、先人至）；治气（避锐击惰）、治心（以静待哗）、治力（以佚待劳）、治变（无击堂堂之阵）四法。
- 适用场景：抢时间/抢机会时，绕远路反而先到；消耗战里挑对手松懈的窗口出手。
- 原文位置：block_02 / 军争第七
- 原文摘录：军争之难者，以迂为直，以患为利……避其锐气，击其惰归。

## F9 · 九变权变框架
- 结构：途有所不由、军有所不击、城有所不攻、地有所不争、君命有所不受；核心心法"杂于利害"（杂于利而务可信，杂于害而患可解）。
- 适用场景：常规该做的不一定做、常规该听的不一定听；每个决策同时算利与害两面。
- 原文位置：block_03 / 九变第八
- 原文摘录：途有所不由，军有所不击，城有所不攻，地有所不争，君命有所不受。

## F10 · 相敌三十二象框架
- 结构：从敌方的动静、言语、尘土、鸟兽、旗鼓等三十余种表象反推其真实状态（如"敌近而静者恃其险也""辞卑而益备者进也""鸟集者虚也"）。
- 适用场景：信息不全时，靠可观察的外部信号推断对手底牌，而不是等情报齐全。
- 原文位置：block_03 / 行军第九
- 原文摘录：敌近而静者，恃其险也；远而挑战者，欲人之进也……鸟集者，虚也。

## F11 · 地形六形六败框架
- 结构：地形六形（通/挂/支/隘/险/远）各有打法；败兵六因（走/弛/陷/崩/乱/北）皆将之过非天灾。
- 适用场景：进入新环境/新市场先判"地形"属性，再选打法；组织失利先查将领/管理而非怪运气。
- 原文位置：block_03 / 地形第十
- 原文摘录：凡地形有通者、有挂者、有支者、有隘者、有险者、有远者……非天之灾，将之过也。

## F12 · 九地人情框架
- 结构：九种境地（散/轻/争/交/衢/重/圮/围/死）各有心理与打法；核心机制"投之亡地然后存，陷之死地然后生""陷于害然后能为胜败"。
- 适用场景：团队散漫或陷绝境时，用环境压力而非说教把人拧成一股绳；先判所处是哪种"地"。
- 原文位置：block_03 / 九地第十一
- 原文摘录：投之亡地然后存，陷之死地然后生……九地之变，屈伸之利，人情之理，不可不察也。

## F13 · 五间先知框架
- 结构：用间五类（乡/内/反/死/生），以反间为枢纽；先知必取于人（知敌之情者），不可取于鬼神象事验度。
- 适用场景：任何"对手在想什么"的信息差问题，把情报当成杠杆最高、成本最低的战略投入。
- 原文位置：block_03 / 用间第十三
- 原文摘录：故用间有五……知之必在于反间，故反间不可不厚也。
