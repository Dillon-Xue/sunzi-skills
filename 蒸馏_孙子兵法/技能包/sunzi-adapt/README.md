# sunzi-adapt（虚实应变与任势）· 使用说明

> 从《孙子兵法》（军形、兵势、虚实、军争四篇）蒸馏出的"临场应变"技能。它管的是**局面已经开打之后**怎么调整、怎么把主动抢回来。

## 这个技能解决什么

计划赶不上变化、对手也在变、你没法照原样硬走——这时候需要的不是更努力，而是"因对手而变"：把对手调度到被动、自己集中而他分散、永远打他虚弱处。一句话：**没有固定打法，能随对手变化取胜才是真本事。**

## 怎么触发（用户会说的自然语言）

- "对方变招了，我该怎么应对？"
- "怎么把主动权抢回来？"
- "资源有限，怎么集中打关键点？"
- "对手最强的时候我该硬刚还是避开？"
- "怎么用明面上的动作掩护真正的动作？"

## 典型用法

1. **先稳不败**：把自身实力和环境量化成客观差距，先赢在账面再动手。
2. **明招+暗手**：正面牵制配侧翼奇兵，循环无穷，别只亮一招。
3. **调动对手**：用假象骗、用利益诱，让他分散兵力，你就能以众击寡。
4. **打虚弱处**：攻其无守、退其难追，避实击虚。
5. **挑窗口**：对手士气盛就避锐、等他松懈再击；抢时间敢绕远反而先到。
6. **造势**：设计险而短的节奏，让态势自己做功，不靠个人硬扛。

## 什么时候不要用

- 你也被对手反间、信息被反过来利用时，虚实会自我抵消。
- 非对抗目标（合作、共存）硬用，会过度博弈、处处设防。
- 实力差距大到技巧救不回时，先积累，别指望奇招翻盘。

## 与另外两个技能的关系

- 先用 **sunzi-strategy** 判断"该不该打、怎么算赢"；
- 再用本技能解决"打起来之后怎么变、怎么抢主动"；
- 带队、进陌生环境、摸对手底牌，看 **sunzi-command**。
