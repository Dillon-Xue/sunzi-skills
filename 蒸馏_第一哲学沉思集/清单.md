# 蒸馏清单 · 《第一哲学沉思集》

> 从笛卡尔《第一哲学沉思集：反驳和答辩》（含六个沉思正文 + 后世学者分析论文）提炼出的技能包。
> 工作目录：`D:/forworkbuddy/2026-08-11-22-06-03/蒸馏_第一哲学沉思集/`

## 一、产出了哪几个技能（7 个）

| 技能 name | 一句话用途 |
| --- | --- |
| meditations-radical-doubt | 推倒重来、从底层原则清算旧信念/知识地基 |
| meditations-find-anchor | 在不确定中找不可动摇的起点、剥离表象看本质 |
| meditations-truth-error-audit | 判断该不该信、避免在不清楚时乱下结论 |
| meditations-sensory-signal | 解读感官/直觉/本能信号，区分真实警报与脑补 |
| meditations-cause-tracing | 追因与因果分析、根因排查 |
| meditations-analysis-method | 系统研究复杂问题、组织论证、把含糊问题化可解 |
| meditations-concept-clarify | 把糊里糊涂的概念从常识提纯为清晰定义 |

## 二、每个技能的触发示例

| 技能 | 用户可能这样说 |
| --- | --- |
| meditations-radical-doubt | "我想把我过去相信的一套东西推倒重来，从根上检查它靠不靠谱" |
| meditations-find-anchor | "在完全不确定该信什么的时候，怎么找到一个不会再动摇的立足点？" |
| meditations-truth-error-audit | "怎么判断一个说法到底该不该信？我老是在没弄清楚的事上乱下结论" |
| meditations-sensory-signal | "我凭直觉做了判断，结果老被表象带偏，怎么分辨信号和脑补？" |
| meditations-cause-tracing | "这个故障根因在哪？怎么往上追到最根本的原因？" |
| meditations-analysis-method | "我要研究一个很复杂的问题，该怎么系统拆解、组织论证？" |
| meditations-concept-clarify | "我对'自由'这个词的理解很糊，怎么提纯成清晰的定义？" |
