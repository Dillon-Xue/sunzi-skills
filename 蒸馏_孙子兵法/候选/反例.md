# 反例候选（配料，仅去重——最终成为每个技能的"什么时候不该用它"）

## X1 · 攻城之灾（硬啃堡垒）
- 错在哪：把攻城当常规手段，修橹轒輼三月不成，蚁附之杀士三分之一城仍不拔。
- 为什么错：攻城是"不得已"，成本与伤亡不成比例。
- 正确做法：上兵伐谋，先让对手内部崩，别先拼城墙。
- 关联：F2 全胜梯度——攻城是最下之策。
- 原文位置：block_01 / 谋攻第三
- 原文摘录：修橹轒輼，具器械，三月而后成……杀士三分之一，而城不拔者，此攻之灾也。

## X2 · 久暴师则国用不足（久战拖垮自己）
- 错在哪：指望"巧之久"，长期在外作战。
- 为什么错：钝兵挫锐、屈力殚货，诸侯乘弊而起，智者不能善后。
- 正确做法：兵贵胜不贵久，速决。
- 关联：P3 兵贵胜不贵久。
- 原文位置：block_01 / 作战第二
- 原文摘录：久则钝兵挫锐，攻城则力屈，久暴师则国用不足。

## X3 · 乱军引胜（外行瞎指挥）
- 错在哪：君不知军而谓之进退、同三军之政与任。
- 为什么错：军士惑且疑，诸侯之难至。
- 正确做法：将能而君不御；战道必胜主曰无战必战可也。
- 关联：P7 君患于军三。
- 原文位置：block_01 / 谋攻第三
- 原文摘录：不知三军之事，而同三军之政，则军士惑矣……是谓乱军引胜。

## X4 · 小敌之坚，大敌之擒（弱硬拼）
- 错在哪：弱势方靠"坚决"正面对抗。
- 为什么错：实力差摆在那，硬就成俘虏。
- 正确做法：少则守、不若则避。
- 关联：P6、F3 兵力对比决策。
- 原文位置：block_01 / 谋攻第三
- 原文摘录：故小敌之坚，大敌之擒也。

## X5 · 兵无恒形，拘泥成法必败
- 错在哪：把某次成功打法当固定阵法刻舟求剑。
- 为什么错：敌情在变，固定态势会被避开。
- 正确做法：因敌变化而取胜者谓之神。
- 关联：P10、F7 虚实。
- 原文位置：block_02 / 虚实第六
- 原文摘录：兵无成势，无恒形，能因敌变化而取胜者，谓之神。

## X6 · 将有五危（性格死穴被利用）
- 错在哪：将领把"必死/必生/忿速/廉洁/爱民"当绝对美德。
- 为什么错：过强即破绽，可被杀、虏、侮、辱、烦。
- 正确做法：五危皆须察，性格优势要设边界。
- 关联：P13。
- 原文位置：block_03 / 九变第八
- 原文摘录：必死，可杀也；必生，可虏也……覆军杀将，必以五危。

## X7 · 兵非贵益多（堆人数）
- 错在哪：以为人多就能赢，盲目扩规模。
- 为什么错：无虑而易敌者必擒于人，规模掩盖没算清。
- 正确做法：足以并力、料敌、取人而已。
- 关联：P14。
- 原文位置：block_03 / 行军第九
- 原文摘录：兵非贵益多也，惟无武进……夫惟无虑而易敌者，必擒于人。

## X8 · 厚而不能使（溺爱部属）
- 错在哪：只关爱不约束，把"爱兵"当不令行。
- 为什么错：骄子不可用，关键时刻叫不动。
- 正确做法：令之以文，齐之以武。
- 关联：P15。
- 原文位置：block_03 / 行军第九、地形第十
- 原文摘录：厚而不能使，爱而不能令，乱而不能治，譬若骄子，不可用也。

## X9 · 费留（战胜不修其功）
- 错在哪：打下来却不巩固成果。
- 为什么错：凶，等于白打。
- 正确做法：非利不动、明主虑之良将修之。
- 关联：P18 慎战。
- 原文位置：block_03 / 火攻第十二
- 原文摘录：夫战胜攻取，而不修其功者凶，命曰"费留"。

## X10 · 主怒而兴师（情绪决策）
- 错在哪：被愤怒/屈辱驱动开战。
- 为什么错：亡国不可复存，死者不可复生，情绪可逆、后果不可逆。
- 正确做法：合于利而动，不合于利而止。
- 关联：P18。
- 原文位置：block_03 / 火攻第十二
- 原文摘录：主不可以怒而兴师，将不可以愠而致战。

## X11 · 间事未发而先闻（情报泄密）
- 错在哪：间谍行动还没发动就走漏。
- 为什么错：间与所告者皆死，体系报废。
- 正确做法：事莫密于间，未发先闻则死。
- 关联：F13 五间。
- 原文位置：block_03 / 用间第十三
- 原文摘录：间事未发而先闻者，间与所告者皆死。

## X12 · 不知诸侯之谋/不用乡导（情报与地利缺失）
- 错在哪：不摸对手联盟、不请向导就深入。
- 为什么错：不能豫交、不能得地利，必败。
- 正确做法：知诸侯之谋、用乡导。
- 关联：F8、F13。
- 原文位置：block_02 / 军争第七、block_03 / 九地第十一
- 原文摘录：不知诸侯之谋者，不能豫交；……不用乡导者，不能得地利。
