# 怎么导入这些技能包

这些是从《第一哲学沉思集》里提炼出来的技能包，一个文件夹是一个技能。下面教你怎么用，不需要任何技术基础。

## 第一步：打开你的 AI 助手的"技能 / 插件"入口

不同助手位置不一样，常见叫法：技能中心、插件、Skills、自定义指令。进去找"导入"或"添加本地技能"。

## 第二步：一次导入一个技能文件夹

- 在 `技能包/` 目录里，你会看到 7 个文件夹，名字像 `meditations-radical-doubt` 这样。
- 点"导入"，**选中 `技能包/` 里的某一个文件夹**（比如 `meditations-find-anchor`），不是选 `技能包/` 整个目录。
- 每个文件夹里只有一个 `SKILL.md` 文件，那就是技能本身。

## 第三步：建议一次只开当前用得上的几个

7 个技能主题相近，全开容易互相"抢活"。建议按场景开：

- 想推翻旧认知、重建知识地基 → 开 `meditations-radical-doubt`
- 想找不确定中的立足点、看穿本质 → 开 `meditations-find-anchor`
- 想判断该不该信、避免乱下结论 → 开 `meditations-truth-error-audit`
- 想分辨感官/直觉信号和脑补 → 开 `meditations-sensory-signal`
- 想追根因、排查责任 → 开 `meditations-cause-tracing`
- 想系统研究复杂问题、把含糊想法讲清楚 → 开 `meditations-analysis-method`
- 想把一个糊的概念提纯成清晰定义 → 开 `meditations-concept-clarify`

用不到的先关掉，要用时再开。

## 第四步：不确定某个技能干嘛的，直接问助手

你可以直接对助手说："你有哪些技能？" 它会把已装的技能列给你。想知道某个技能什么时候用，看它描述里写的"什么时候用它"和"什么时候不该用它"就行。

## 注意

- 我**没有**自动帮你装，因为自动安装要改你助手的配置文件，写坏了不好修。你按上面手动导入最稳。
- 想让我直接帮你装，跟我说一声就行。
