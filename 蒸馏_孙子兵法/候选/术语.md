# 术语候选（配料，去重后回写进骨架.md 关键概念）

## 庙算
- 作者的定义：开战前用五事七计推算胜负概率，得算多者胜。
- 跟日常用法的区别：日常当"谋划"，作者量化成可比较的胜负概率。
- 原文位置：block_01 / 始计第一
- 原文摘录：夫未战而庙算胜者，得算多也。

## 全
- 作者的定义：全国、全军……完整保全地取胜，破是次一等。
- 跟日常用法的区别：日常"全"=全部，作者指"不破坏地拿下"。
- 原文位置：block_01 / 谋攻第三
- 原文摘录：全国为上，破国次之。

## 形
- 作者的定义：实力客观积累（度→量→数→称→胜），守则不足攻则有余。
- 跟日常用法的区别：日常指形状，作者指可测量的实力对比。
- 原文位置：block_02 / 军形第四
- 原文摘录：地生度，度生量，量生数，数生称，称生胜。

## 势
- 作者的定义：态势与节奏（险、短、节），如彍弩发机、圆石下山。
- 跟日常用法的区别：日常偏抽象气势，作者指可营造的物理性压强。
- 原文位置：block_02 / 兵势第五
- 原文摘录：故善战者，求之于势，不责于人。

## 奇正
- 作者的定义：正合奇胜，正面牵制+侧翼奇兵，相生无穷。
- 跟日常用法的区别：日常"奇"=奇怪，作者指与"正"相对的标准战术变量。
- 原文位置：block_02 / 兵势第五
- 原文摘录：凡战者，以正合，以奇胜。

## 虚实
- 作者的定义：敌实我避、敌虚我冲；我专敌分则众寡易位。
- 跟日常用法的区别：日常"虚"=空虚，作者指力量集中度的可调变量。
- 原文位置：block_02 / 虚实第六
- 原文摘录：兵之胜，避实而击虚。

## 九变
- 作者的定义：途有所不由等五"不"加君命有所不受的临机权变。
- 跟日常用法的区别：日常"变"=变化，作者指"该放弃时不循常例"的决断。
- 原文位置：block_03 / 九变第八
- 原文摘录：君命有所不受。

## 死地／亡地
- 作者的定义：疾战则存不疾则亡之处，投之然后生。
- 跟日常用法的区别：日常是绝境贬义，作者指"被迫团结、反能取胜"的催化点。
- 原文位置：block_03 / 九地第十一
- 原文摘录：投之亡地然后存，陷之死地然后生。

## 用间
- 作者的定义：取敌情于人的五类间谍体系，反间为枢纽。
- 跟日常用法的区别：日常"间"偏贬义间谍，作者抬到"三军所恃而动"的战略高度。
- 原文位置：block_03 / 用间第十三
- 原文摘录：三军之所恃而动也。
