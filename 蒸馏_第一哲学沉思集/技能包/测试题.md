# 《第一哲学沉思集》技能包触发测试

> 本文件留给用户：以后改了任何一条 description，可拿原题重跑验证，不用重新造题。
> 测试方式：仅依据各技能的 **name + description**（不给正文）判断应触发哪个，或由已有通用能力处理。

## 参测技能

| name | 一句话用途 |
| --- | --- |
| meditations-radical-doubt | 推倒重来、从底层原则清算旧信念/知识地基 |
| meditations-find-anchor | 在不确定中找不可动摇的起点、剥离表象看本质 |
| meditations-truth-error-audit | 判断该不该信、避免在不清楚时乱下结论 |
| meditations-sensory-signal | 解读感官/直觉/本能信号，区分真实警报与脑补 |
| meditations-cause-tracing | 追因与因果分析、根因排查 |
| meditations-analysis-method | 系统研究复杂问题、组织论证、把含糊问题化可解 |
| meditations-concept-clarify | 把糊里糊涂的概念从常识提纯为清晰定义 |
