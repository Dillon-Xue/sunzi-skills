# sunzi-strategy（谋略预判与全胜）· 使用说明

> 这是从《孙子兵法》（始计、作战、谋攻三篇）蒸馏出的一个"决策前判断"技能。它不教你怎么执行，只教你在**动手之前**先算清楚该不该做、能不能赢、划不划算。

## 这个技能解决什么

你有没有过这种时刻：一个新方向、一个大项目、一笔大投入摆在面前，脑子里一团"感觉能行但又没底"。这个技能给你一套**事前对照清单**，把"我觉得行"变成可以逐项打分的判断。

核心一句话：**开打之前胜负已经大致定了——先确保自己不输，再去图赢；能用更低代价完整拿下，就别硬碰。**

## 怎么触发（用户会说的自然语言）

- "这件事该不该接？"
- "我们跟对方打，有几成胜算？"
- "投入这么大，值不值得？"
- "现在是不是出手的时候？"
- "弱势的时候该怎么应对？"

## 典型用法

1. **列五件事对照表**：目标是否上下同欲、时机环境、资源地形、关键人、制度补给——先看自己五项里哪项是短板。
2. **校七问找差距**：和对手逐项比（目标更齐？将领更强？环境更占？……），弱在哪先补哪。
3. **按实力定动作**：优势大就围、五比一就攻、两倍就分割、相当就纠缠、弱就守、悬殊就避。
4. **把"全"当目标**：优先用谋略/外交化解，硬打是下策。
5. **算代价**：速决优先，久拖必自伤；摸透对手也诚实估自己。

## 什么时候不要用

- 已经拍板要做、只差执行步骤——它只管"该不该"，不教"怎么干"（看 sunzi-adapt / sunzi-command）。
- 非对抗性目标（合作、探索）硬套"赢"的框架，会过度算计。
- 对手不可理喻时，"不战而屈人"会让你错失该硬打的窗口。

## 来源与边界

蒸馏自《孙子兵法》始计/作战/谋攻篇。它假设你是理性、可动员、信息可侦察的一方；若你这边团队不齐心、信息被截留，"知己"在自己内部就先崩了。这是该技能不会替你处理的前置问题。
