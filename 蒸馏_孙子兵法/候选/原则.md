# 原则候选（主料）

## P1 · 兵者国之大事，不可不察
- 适用条件：任何重大投入/承诺前。
- 它反对什么：拍脑袋、凭情绪或面子启动大事。
- 原文位置：block_01 / 始计第一
- 原文摘录：兵者，国之大事，死生之地，存亡之道，不可不察也。

## P2 · 多算胜，少算不胜，而况于无算
- 适用条件：决策前要不要花时间推演。
- 它反对什么：不做推演就动手、指望临场发挥。
- 原文位置：block_01 / 始计第一
- 原文摘录：夫未战而庙算胜者，得算多也……多算胜，少算不胜，而况于无算乎？

## P3 · 兵贵胜，不贵久；不尽知害不能尽知利
- 适用条件：项目/战争拖长、成本失控时。
- 它反对什么：为了"巧"而久拖，只算收益不算代价。
- 原文位置：block_01 / 作战第二
- 原文摘录：故兵闻拙速，未睹巧之久也……故不尽知用兵之害者，则不能尽知用兵之利也。

## P4 · 不战而屈人之兵，善之善者
- 适用条件：能用更低的代价让对方就范时。
- 它反对什么：把"打服"当成唯一选项、为战而战。
- 原文位置：block_01 / 谋攻第三
- 原文摘录：是故百战百胜，非善之善者也；不战而屈人之兵，善之善者也。

## P5 · 知彼知己，百战不殆
- 适用条件：进入任何对抗/竞争前。
- 它反对什么：只盯着自己、或只侦察对手而误判自身。
- 原文位置：block_01 / 谋攻第三、block_03 / 地形第十
- 原文摘录：知彼知己，百战不殆……知彼知己，胜乃不殆；知天知地，胜乃可全。

## P6 · 小敌之坚，大敌之擒
- 适用条件：弱势方硬碰硬时。
- 它反对什么：弱者靠"硬气"正面对抗强者。
- 原文位置：block_01 / 谋攻第三
- 原文摘录：故小敌之坚，大敌之擒也。

## P7 · 君患于军三：縻军、惑军、疑军
- 适用条件：外行领导内行、远端微观干预时。
- 它反对什么：不懂一线却替一线做具体进退决策。
- 原文位置：block_01 / 谋攻第三
- 原文摘录：不知军之不可以进而谓之进……是谓乱军引胜。

## P8 · 胜可知而不可为；善守藏九地，善攻动九天
- 适用条件：求胜心切、想"强行制造胜利"时。
- 它反对什么：指望靠主观努力硬扭胜负的必然。
- 原文位置：block_02 / 军形第四
- 原文摘录：故曰：胜可知，而不可为……善守者，藏于九地之下；善攻者，动于九天之上。

## P9 · 善战者胜于易胜，无智名无勇功
- 适用条件：追求"漂亮仗""以少胜多"的叙事时。
- 它反对什么：把险胜当能力、把容易赢的仗当成没本事。
- 原文位置：block_02 / 军形第四
- 原文摘录：古之所谓善战者，胜于易胜者也……无智名，无勇功。

## P10 · 兵无成势，无恒形，避实击虚
- 适用条件：套用过往成功打法、刻舟求剑时。
- 它反对什么：把某次成功当成可复制的固定阵法。
- 原文位置：block_02 / 虚实第六
- 原文摘录：故兵无成势，无恒形，能因敌变化而取胜者，谓之神。

## P11 · 避其锐气，击其惰归（治气）
- 适用条件：对手士气正盛、我方想硬碰时。
- 它反对什么：在对方状态最好的窗口决战。
- 原文位置：block_02 / 军争第七
- 原文摘录：故善用兵者，避其锐气，击其惰归，此治气者也。

## P12 · 无恃其不来，恃吾有以待之
- 适用条件：赌对手"应该不会来"、侥幸心理时。
- 它反对什么：把安全建立在对手不行动的前提上。
- 原文位置：block_03 / 九变第八
- 原文摘录：无恃其不来，恃吾有以待之；无恃其不攻，恃吾有所不可攻也。

## P13 · 将有五危：必死/必生/忿速/廉洁/爱民
- 适用条件：识别自己或对手将领的性格破绽时。
- 它反对什么：把"优点"当绝对好——过强则成可被利用的死穴。
- 原文位置：block_03 / 九变第八
- 原文摘录：故将有五危：必死，可杀也；必生，可虏也……不可不察也。

## P14 · 兵非贵益多，惟无武进
- 适用条件：靠堆人数/堆资源解决问题时。
- 它反对什么：用规模掩盖"没算清、轻敌"。
- 原文位置：block_03 / 行军第九
- 原文摘录：故兵非贵益多也，惟无武进，足以并力、料敌、取人而已。

## P15 · 视卒如婴儿/爱子，但厚而不能使则不可用
- 适用条件：管理者只讲关爱、不讲纪律时。
- 它反对什么：把"爱兵"理解成不约束、不令行。
- 原文位置：block_03 / 地形第十、行军第九
- 原文摘录：视卒如爱子，故可与之俱死。厚而不能使，爱而不能令……譬若骄子，不可用也。

## P16 · 知天知地，胜乃可全
- 适用条件：只懂对手和自身、忽略环境/时机时。
- 它反对什么：把"知己知彼"当成充分，漏掉天地（环境）变量。
- 原文位置：block_03 / 地形第十
- 原文摘录：知彼知己，胜乃不殆；知天知地，胜乃可全。

## P17 · 投之亡地然后存，陷之死地然后生
- 适用条件：团队松懈、需要背水一战时。
- 它反对什么：在还有退路时指望人爆发出死战意志。
- 原文位置：block_03 / 九地第十一
- 原文摘录：投之亡地然后存，陷之死地然后生。

## P18 · 非利不动，非得不用，非危不战；主不可怒而兴师
- 适用条件：情绪上头想"干它"、或被激将时。
- 它反对什么：愤怒/屈辱驱动的开战决策。
- 原文位置：block_03 / 火攻第十二
- 原文摘录：非利不动，非得不用，非危不战。主不可以怒而兴师，将不可以愠而致战。

## P19 · 先知必取于人，不可取于鬼神
- 适用条件：靠直觉/占卜/经验主义猜对手时。
- 它反对什么：用玄学或自我感觉替代真实情报。
- 原文位置：block_03 / 用间第十三
- 原文摘录：先知者，不可取于鬼神，不可象于事，不可验于度，必取于人，知敌之情者也。

## P20 · 反间不可不厚
- 适用条件：做情报体系、安插信息源时。
- 它反对什么：平均用力、不重视最关键的反向信息节点。
- 原文位置：block_03 / 用间第十三
- 原文摘录：五间之事，主必知之，知之必在于反间，故反间不可不厚也。
