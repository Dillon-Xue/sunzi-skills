# 《孙子兵法》骨架

## 一句话主旨

在资源有限、信息不全、对手也会博弈的不确定环境里，靠"先立于不败、再求可胜"的预判与应变，用最小的代价拿到确定的结果。

## 整体结构

全书十三篇可归为四条递进主线：先讲**庙算预判**（算清该不该打），再讲**形/势/虚实**（凭什么能赢、怎么造势、怎么避实击虚），接着讲**九变/地形/行军**（落地到具体地形、敌情、临机权变），最后回到**慎战全胜与用间**（把代价和情报抬到战略高度）。

| 部分 | 讲什么 | 与前一部分的关系 |
| --- | --- | --- |
| 始计 / 作战 / 谋攻 | 庙算五事七计、速胜、全胜不战 | 起点：先判断该不该打、怎么以最小代价胜 |
| 军形 / 兵势 / 虚实 / 军争 | 先为不可胜、任势、避实击虚、以迂为直 | 递进：从"立于不败"到"主动塑造胜机" |
| 九变 / 行军 / 地形 / 九地 | 临机权变、相敌、地形六形、九地人情 | 落地：把原则用到具体地形与敌情 |
| 火攻 / 用间 | 慎战、先知必取于人 | 收束：把代价与情报抬到战略层，呼应开头 |

## 作者试图解决的核心问题

孙武面对的是"国君一声令下就要兴师十万、千里远征，但胜败在开打前就大致注定"的现实。他要解决的核心问题是：**在信息不全、对手也在算计、资源一旦投入就难以收回的环境里，怎么把"赢"从一个靠运气的偶然，变成一个可以事前设计、事中塑造的确定结果。** 全书所有篇目都围绕"先知—先胜—应变—控代价"这条线展开。

## 核心主张

1. **胜在战前已定**：善战者先为不可胜、立于不败之地，再等敌人露出破绽；胜兵先胜而后求战，败兵先战而后求胜。
2. **不战而屈人之兵是最高效的胜利**：百战百胜不算善，不战而全争于天下才是——把"全"（完整、代价最小）当成目标，而非杀伤本身。
3. **知己知彼是胜负的硬前提**：只知己不知彼胜半，全不知每战必殆；知天知地才能胜乃可全。
4. **避实击虚、因敌变化才是"神"**：兵形象水，避高趋下、避实击虚；没有固定态势，能因敌变化而取胜者谓之神。
5. **任势不责人**：善战者求之于势，不苛求手下个人勇武，而是营造"如转圆石于千仞之山"的态势，择人而任势。
6. **杂于利害、君命有所不受**：智者之虑必同时算利与害；为保大局，该放弃的城、该不走的路、甚至该违抗的君命都要敢舍。
7. **慎战与先知互为表里**：非利不动、非危不战，主不可怒而兴师；而"先知"不能靠鬼神占卜，必须取于知敌之情的人——用间是成本最低、杠杆最高的投入。

## 关键概念

| 概念 | 作者的定义 | 跟日常用法的区别 |
| --- | --- | --- |
| 庙算 | 开战前用五事七计推算胜负概率，得算多者胜 | 日常只当"谋划"，作者把它量化成可比较的胜负概率 |
| 全 | 全国、全军、全旅……完整保全地取胜，破是次一等 | 日常"全"是"全部"，作者指"不破坏地拿下" |
| 形 | 军事实力的客观积累（度→量→数→称→胜），守不足攻有余 | 日常"形"是形状；作者指可测量的实力对比 |
| 势 | 态势与节奏（险、短、节），如彍弩发机、圆石下山 | 日常"势"偏抽象气势；作者指可被营造的物理性压强 |
| 奇正 | 正合奇胜，正面牵制+侧翼奇兵，二者相生无穷 | 日常"奇"是奇怪；作者指与"正"相对的标准战术变量 |
| 虚实 | 敌实我避、敌虚我冲；我专敌分则众寡易位 | 日常"虚"是空虚；作者指力量集中度的可调变量 |
| 九变 | 途有所不由等五条"不"加君命有所不受的临机权变 | 日常"变"是变化；作者指"该放弃时不循常例"的决断 |
| 死地 / 亡地 | 疾战则存不疾则亡之处，投之然后生 | 日常是绝境贬义；作者指"被迫团结、反能取胜"的催化点 |
| 用间 | 取敌情于人的五类间谍体系，反间为枢纽 | 日常"间"偏贬义间谍；作者抬到"三军所恃而动"的战略高度 |

## 盲点与边界

### 时代与身份局限

作者站在公元前 5 世纪诸侯征伐、胜负即国运的时代，"兵者国之大事"的前提是零和、可动员举国的战争。他把"速胜""因粮于敌"当成通则，但现代很多竞争（商业、科研、个人成长）不是一次性决战，而是长期多回合博弈，强行套"兵贵胜不贵久"会牺牲长期建设。

### 未被证明的假设

全书默认"我方是理性、统一、信息可被侦察的博弈方"。但"上下同欲""令素行"把组织内部完全协同当成了前提——现实中团队目标分歧、信息被截留，"知彼知己"在组织内部就先崩了。孙武没处理的，是如何在自己一方不齐心时应用这套方法。

### 方法的失效场景

- **信息不对称被对手反过来利用**：作者主张"形人而我无形"，但若对手也精通虚实、且我方间谍被反间渗透，方法会自我抵消。
- **非对抗性目标不适用**：用来"赢"的框架，对"共存""合作创造""探索未知"这类目标几乎无解，硬用会变成处处设防、过度算计。
- **实力悬殊到形不可造时**：先为不可胜仍成立，但"称生胜"意味着实力差距过大时，势与奇正都救不回。

### 最强的反驳

"不战而屈人之兵"听着最优，但历史上多数时候对手不会因为你有谋略就主动认输；"伐谋""伐交"需要对手也讲道理、有可谈的空间。当对方是亡命之徒或不可理喻的力量时，全胜理想会让己方在准备"屈人"的过程中错失"击敌"的窗口。换言之，孙武低估了"有些对手只能打服、不能说服"的情形。
