# 将道·地形·情报

## 什么时候用它

你成了那个"带队的人"：要管一群人、要进一个不熟的环境、或者必须搞清楚对手到底在想什么。如果你 solo 干活、既不带人也不摸对手，这个技能不适用。

## 核心判断

带人不是靠个人勇武，而是靠机制：把对的人放在对的态势里、用共同压力把散兵拧成一股绳、用情报替代猜测。最危险的不是敌人，而是自己的性格死穴、对环境的误判、和靠侥幸代替准备。

## 怎么做

1. 先判"地形"：进入新环境先分类——是通畅可往来、是易进难出、是双方必争、是险窄、还是势均难挑？不同地形打法完全不同；组织失利先查管理，别怪运气。
2. 临机权变：常规的"该做"不一定做、"该听"不一定听；每个决定同时算利与害两面，该放弃的城、该不走的路、甚至该违抗的命令要敢舍。
3. 识人破绽：别把"优点"当绝对好——过于必死、必生、易怒、爱洁、爱民，过强即成可被利用的死穴。
4. 带队伍：关爱与纪律并行，只爱不令就是骄子不可用；规模不是答案，算清+不轻敌才是。
5. 摸对手底牌：靠可观察的外部信号反推（动静、言语、尘土、旗鼓），信息差问题上把"情报"当成杠杆最高、成本最低的投入，并重点经营最关键的那个反向信息节点。
6. 控代价与情绪：不合算不动、没把握不用、不到危急不战；绝不为愤怒或屈辱开战，也别把安全建立在"对手应该不会来"上。

## 判断标准

做对了会看到：环境分类清晰、团队在压力下反而齐心、关键情报准确、决策同时考虑了利与害。
做错了会看到：堆人数代替算清、溺爱部属叫不动、性格被对手拿捏、情报泄密、或因情绪/侥幸启动而不可收拾。

## 什么时候不该用它

- 你这边团队不齐心、信息被截留时，"知己"在内部先崩，这套方法的前提不成立。
- 对手也精通虚实且你方被反间渗透，情报体系会反噬。
- 非对抗性目标用它，会变成过度设防、全员互防。

## 出处

来自《孙子兵法》九变第八、行军第九、地形第十、九地第十一、火攻第十二、用间第十三。

原文：投之亡地然后存，陷之死地然后生；先知者，不可取于鬼神……必取于人，知敌之情者也。
