# 怎么用这些技能包

这下面是从《孙子兵法》里提炼出的 **3 个技能**，每个是一个独立文件夹（里面是 `SKILL.md` 说明 + `README.md` 使用说明）。它们不是读书笔记，而是能让你在具体问题里直接调用的"操作指令"。

## 导入步骤（手动，最稳）

1. 打开你的 AI 助手（WorkBuddy），找到「技能 / 插件」入口。
2. 点「导入」，选中 `技能包/` 里的**某一个技能文件夹**（例如 `sunzi-strategy`），不是 `技能包/` 这个大目录本身。
3. 重复导入另外 2 个（`sunzi-adapt`、`sunzi-command`）。
4. 建议一次只开启当前用得上的几个，用不到的关掉，避免互相抢触发。
5. 不确定某个技能干嘛的，直接问助手："你有哪些技能？"

## 三个技能分别管什么

- **sunzi-strategy（谋略预判与全胜）**：动手之前先算清楚"该不该做、能不能赢、划不划算"。
- **sunzi-adapt（虚实应变与任势）**：打起来之后怎么临场调整、把主动抢回来。
- **sunzi-command（将道·地形·情报）**：带队伍、进陌生环境、摸对手底牌、控住代价。

## 推荐顺序

先 `sunzi-strategy` 判断要不要打 → 再 `sunzi-adapt` 解决怎么变 → 最后 `sunzi-command` 落地带人。三者也可以单独用。

> 注意：我**没有自动帮你安装**，因为自动安装要改助手的配置文件，写坏了不好修。按上面手动导入最稳。想让我直接装进用户级技能目录，跟我说一声即可。
