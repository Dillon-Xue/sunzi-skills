# 《第一哲学沉思集》可复用框架提取

> 提取原则：只收"可迁移的思考结构"——固定步骤、固定维度、对比/取舍结构。
> 不收：纯哲学命题（"上帝存在""我思故我在"本身）、仅限本书场景的观点、常识包装。
> 每条均附原文摘录（均取自 28 个 block 原文）。

---

## 一、怀疑与基础清理类

### F1 系统性怀疑·基础优先检查法
- 结构：①承认旧观念整体可疑 → ②不必逐一证伪，只要在某处找到一点可疑就整类抛弃 → ③先检查"形成旧观点的底层原则/基础"，因为基础崩则大厦塌。
- 适用场景：想推倒重来、重建知识体系或评估一套信念可靠性时。
- 原文位置：第 1 块
- 原文摘录："基础的破坏会使一座大厦的其他部分倒塌，所以我会首先检查那些形成我以前观点的原则。"

### F2 怀疑强度递进假设法
- 结构：由弱到强逐层加码假设——感官会骗人 → 我可能在做梦（醒/梦无法区分） → 有一个全能精怪/上帝专门骗我。每升一级，对确定性的压力测试更狠。
- 适用场景：压力测试一个论断/系统的抗质疑能力；做最坏情况推演。
- 原文位置：第 1 块
- 原文摘录："因此我要假设有一个精怪……用全部的精力欺骗我，我将认为天空、陆地、颜色、形状、声音以及所有其他外界的事物，都是它用来欺骗我使我轻信的一些假象和骗局。"

### F3 延期判断·对抗习惯法
- 结构：对无法确信的旧观念，主动假装它们错误、反复权衡成见，直到旧习惯不再偏向任一方、判断不被坏习惯控制。核心动作是"推迟判断"而非强行相信。
- 适用场景：清除根深蒂固的偏见、旧习惯信念；在不能下结论前 Hold 住。
- 原文位置：第 1 块
- 原文摘录："出于这个原因，我不对任何错误的东西给予信任，并且做好准备来对付这个大骗子的欺骗手段，让它没有可能强加给我任何东西……至少做我能力以内的事（也就是推迟我的判断）。"

### F4 信息源可信度分层法
- 结构：把通过感官得到的东西按可信度分层——复合具体事物（我坐在火炉旁）最易被疑；梦中经验与清醒无法区分；而"简单、普遍的元素"（颜色、形状、广延、数目等）是真实存在的摹本，最可靠。
- 适用场景：评估证据/信息源可靠性时，区分"复合表象"与"简单基础元素"。
- 原文位置：第 1 块
- 原文摘录："尽管这些一般的东西，比如（一个身体中的）眼睛、脑袋、手以及此类东西可能是幻想的，可是同时我们也要承认至少有一些更简单、更普遍的东西是真实存在的。"

## 二、寻找确定点与本质识别类

### F5 阿基米德点·假设归谬法
- 结构：假定所见一切为假、逃避一切可怀疑之物 → 沿路走直到撞上一个绝对确定、无可置疑的点（固定的"不动点"）→ 以此为希望支点。
- 适用场景：在全面不确定中，寻找不可撼动的起点/锚点。
- 原文位置：第 2 块
- 原文摘录："阿基米德认为，将地球从它原来的地方移到另一个地方，仅仅需要一个固定的、不动的点；同样，如果我足够幸运，发现了一件确定的无可置疑的事，那么我就有权利抱很大的希望了。"

### F6 我思·反证推导法
- 结构：提出"某物骗我 / 我说服自己某物存在" → 若我被骗、被说服，则"我存在"必为真（被骗的前提是存在）→ 无论怎样怀疑，存在不可被消除。
- 适用场景：从"被作用/被影响"反推"主体存在"；证明某不可怀疑项。
- 原文位置：第 2 块
- 原文摘录："所以，如果他骗我，那就证明我是存在的；我也愿意让他尽他的意愿来骗我，只要我想到我是什么东西，他就不会使我什么都不是。"

### F7 减法剥离·本质识别法
- 结构：列出"我以前以为我是谁"的全部旧观念 → 逐个质疑、撤销所有被新证据冲击的部分 → 留下的确定无疑部分即本质。
- 适用场景：想弄清一个事物/自我真正本质（区别于偶然属性）时做剥离。
- 原文位置：第 2 块
- 原文摘录："对于之前的观点，我会从中撤销所有可能被我刚才提出的观点冲击的东西，使留下来的部分确定无疑、完全可靠。"

### F8 蜡分析·属性剥离法
- 结构：①举一个具体物体 → ②列出其全部感官/表面属性（色、香、硬、形…）→ ③观察其变化，剥离可变属性 → ④剩下由理智（非想象）把握的不变本质（可延伸、可变、可变动）。
- 适用场景：区分事物"表象"与"本质"；穿透感官误导看实质。
- 原文位置：第 3 块
- 原文摘录："让我们仔细考虑一下，去掉所有不属于蜡的，还留下什么？当然，除了延伸的、有伸缩性的、可以变动的东西，其他什么也没有。"

### F9 感官 vs 理智 认知等级法
- 结构：对一物的认识有两条路径——感官/想象得到的是可变表象；理智直觉得到的是本质。判断"我到底怎么认识 X"时依此分级：表象层 < 本质层。
- 适用场景：评估自己对某事的认识深度；辨别"我以为我看见"和"我真正理解"。
- 原文位置：第 3 块
- 原文摘录："既然现在我已经清楚认识到，合理地讲，我们是通过我们心里的理智功能，而不是通过感觉或者通过想象的能力来领会物体。"

## 三、思维分类与真理标准类

### F10 思维三分法（观念 / 意志情感 / 判断）
- 结构：把心里一切活动归入三类——①观念（事物的影像）；②意志或情感（想要、害怕、赞成、否认）；③判断（在观念上附加肯定/否定）。错误只可能落在"判断"这一类。
- 适用场景：定位错误/偏差的来源；做认知审计时先给思维归类。
- 原文位置：第 4 块
- 原文摘录："在我的各种思维中，有些是事物的影像……但是，其他思维也有其他形式，比如想要、害怕、赞成、否认……这类思维被叫作意志或情感，另外的叫判断。"

### F11 清楚感知真理准则
- 结构：单条总则——凡被我清楚、明显感知到的都是真的。作为一切判断的元标准。
- 适用场景：建立个人/组织的知识可靠性标准；决定可否下判断。
- 原文位置：第 4 块
- 原文摘录："我好像已经可以建立一个第一总则：我所清楚感知到的都是正确的。"

### F12 观念来源三分法
- 结构：心里的观念分三类来源——①与生俱来的；②偶然的（来自外部事物）；③由自身形成的（虚构）。用于追溯任一观念的成因。
- 适用场景：追问"这个想法从哪来"；辨别内源/外源/虚构。
- 原文位置：第 4 块
- 原文摘录："一些似乎是与生俱来的，一些是偶然的，其他的由自身形成（或创造）。"

## 四、因果与存在论证类

### F13 因果充足·客观实在性原则
- 结构：①结果不能来自比它更不完满的原因；②观念里的"客观实在性"必须来自至少包含同等实在性的原因；③不完满不能产生更完满。据此从观念上溯其因。
- 适用场景：追溯某事物/观念的成因；论证"某东西必有某来源"。
- 原文位置：第 5 块
- 原文摘录："在动力的、总的原因里，一定至少比在结果里有更多的实在性。"

### F14 因果链逐级上溯至第一因法
- 结构：从某结果（如我心里的观念）→ 追问其原因 → 再追问原因的原因 → ……直到不能再退、得到"第一因/样本"；禁止无限后退。
- 适用场景：根因分析；避免"无限追问"时设定终止条件。
- 原文位置：第 5 块
- 原文摘录："因为就像客观存在的模型由于观念的本性而客观地属于观念一样……尽管可能是这样，一个观念产生于另一个观念，但是这不能无限地继续下去；因为最后我们必须得到一个观念，它的原因就像一个样本。"

### F15 概念属性归并原则（完满性筛选）
- 结构：列举某核心概念属性时，先列具体清单 → 发现列不完 → 跳到一条通用筛选原则："凡我清楚确定为真实正确、且传达完满性的，都包含在此概念中"。用来决定哪些属性属于该概念。
- 适用场景：界定一个复杂概念的本质属性；从零散特征收敛到统一定义。
- 原文位置：第 5 块（亦见第 25 块深化）
- 原文摘录："所有我清楚确定为真实和正确的，以及传达出完满性的，都完全包含在这个观念里了。"

### F16 持续创造 / 保存论证法
- 结构：①我的存在持续到此刻 → ②每一瞬间都需要被"重新产生/保存" → ③创造与保持只有推理差别、无实在差别 → ④故我必持续依赖一个不同于我的存在体。
- 适用场景：论证"当下状态需要持续的外在支撑"；依赖关系分析。
- 原文位置：第 6 块
- 原文摘录："创造和保持的区别只是推理的区别。"

### F17 因果链递归追溯至第一因法（存在版）
- 结构："我从谁得到存在？"→ 自己？父母？其他？逐步上溯；每一步原因若非自因，就再问其来源 → 直到最后原因 = 上帝。且"无限追问无用"，因问题在"保存"不在"产生"。
- 适用场景：组织/系统溯源；追究责任/来源的终极点。
- 原文位置：第 6 块
- 原文摘录："一步一步，直到我们到了最后一个原因，它就是上帝。"

### F18 创造者印记类比法
- 结构：创造者把自身"记号/形象"印在作品上，就像工匠在作品上留印记；由此解释"为何我心里天然有创造者的观念"。结构：作品 → 必含制造者印记 → 从印记反推制造者。
- 适用场景：从"产物中的特征"反推"来源者的特征"。
- 原文位置：第 6 块
- 原文摘录："就像工匠在自己的作品上印上记号；这个记号不一定是和作品本身不同的东西。"

## 五、错误诊断与避免类

### F19 错误二元成因分析法（理解 + 意志）
- 结构：错误 = 理解（仅提供观念、不判断）与意志/自由意志（范围大于理解）两因结合 → 意志扩展到理解不及之处并轻率判断 → 即犯错。诊断时拆成"知"与"决"两端。
- 适用场景：复盘"我为什么会错/被骗"；决策失误根因分析。
- 原文位置：第 7 块
- 原文摘录："我发现它们是由两个原因结合形成的，即我心里的知识和选择的能力或自由意志的力量，也就是说，是理解和意愿。"

### F20 存在等级定位法（至上存在体与无之间）
- 结构：人处在"至上完满存在体"与"无/非存在"之间；越趋向完满越不犯错，越混入"无"越易错。用以定位自身当前状态。
- 适用场景：自我定位/状态评估；判断一个主体是否处于"易错区间"。
- 原文位置：第 7 块
- 原文摘录："我感觉我是在上帝和无中间的东西，也就是说，我被以这样一种方式放置在至上存在体和不存在体之间。"

### F21 避免错误·意志限界 / 悬置判断法
- 结构：①只对清楚明白之物下判断 → ②不清楚明白则不做判断 → ③通过反复沉思把"不判断的决心"刻入记忆形成习惯。
- 适用场景：避免草率决策/判断；信息不足时的正确姿势。
- 原文位置：第 8 块
- 原文摘录："如果我对我没有足够认识清楚的东西放弃判断，显然，我把这一点做得很好，没有犯错。"

### F22 两种免错方法对比（完美依赖 vs 可行可控）
- 结构：方法A——获得对所有事物的清晰知识（依赖外部至上智慧赋予）；方法B——在不清楚时"不下判断"的决心（自身可控）。对比"理想但依赖外援"与"可行且自控"。
- 适用场景：在"做不到完美"与"可控动作"之间做方法取舍。
- 原文位置：第 8 块
- 原文摘录："如果他没有给我因为我之前说的第一个方法而从不犯错的能力（这种能力依靠所有我对能够仔细考虑的东西的清晰明显的知识），他至少在我的力量里留下了其他的方法，那就是在我没有清楚明白事情的真相时不做判断的决心。"

## 六、本质、存在与依赖类

### F23 本质独立·属性必然法（三角形例）
- 结构：我能清楚想到 X 的本质属性 → 这些属性不依赖我的思维、非我虚构 → 它们属于 X 的本质（即便我从未想过）。用"可清楚领会即属本质"判定必然属性。
- 适用场景：区分事物"本质属性"与"我临时想到的东西"。
- 原文位置：第 9 块
- 原文摘录："三角之和等于两个直角……尽管当我第一次想到一个三角形的时候，我从来没有想过这些事，但也不能因此说这些是我虚构的。"

### F24 存在不可离于本质·类比法（山与谷）
- 结构：存在是"至上完满"这一本质的必要属性，正如山谷不能从山分离。结构：想 X 完满 → 存在是完满性之一 → 故 X 必存在（类比"无谷之山"不成立）。
- 适用场景：论证"某属性不可从某本质剥离"；用熟悉类比支撑抽象命题。
- 原文位置：第 9 块
- 原文摘录："存在决不能从上帝的本质中分离出来，就像三角形的三角之和等于两个直角不能从（直线）三角形的本质中分离出来，或者不能把山的观念从山谷中分出。"

### F25 确定性依赖链法（一切知识依赖根本保障）
- 结构：清楚感知 → 相信为真 → 但若忽视根本保障（上帝），本性易变可怀疑 → 故须有根本保障才能保证确定性。结构：知识 → 依赖保障 → 无保障则动摇。
- 适用场景：审视"我的知识体系最终靠什么兜底"。
- 原文位置：第 10 块
- 原文摘录："所有知识的确定性和真理都仅仅依靠真正的上帝的知识，因此，在我知道上帝之前，我不会有任何其他东西的完满的知识。"

## 七、认知能力与经验审查类

### F26 想象 vs 纯粹智力区分法
- 结构：能"理解"（智力）不代表能"想象"；想象需特别集中注意力且依赖身体，智力不需。用"千边形"测试——可理解不可想象 → 二者不同。
- 适用场景：区分"我懂了"与"我能表象"；判断某能力是否依赖载体。
- 原文位置：第 11 块
- 原文摘录："我清楚地认识到我需要特别集中注意力去想象，而不需要这样去理解。"

### F27 感觉信念三段审查法
- 结构：①回想迄今通过感官感知到的、并相信它们的基础；②检查后来迫使我怀疑它们的理由；③考虑现在必须相信哪些。回忆基础 → 检查怀疑 → 重估。
- 适用场景：评估经验证据/感官报告的可靠性；复盘"我凭什么相信X"。
- 原文位置：第 11 块
- 原文摘录："首先，我应该在记忆里回想一下迄今为止我通过感官感知到的东西有哪些是真的，以及我相信它们的基础；接下来，我会检查从那时起迫使我怀疑它们的理由；最后，我会考虑它们中的哪些我现在必须相信。"

### F28 部分—整体完满性法
- 结构：单个创造物孤立看可能不完满，但作为全宇宙的一部分显完满。避免对局部单独下"是否完满"的结论。
- 适用场景：评价局部与系统的关系；避免孤立判断优劣。
- 原文位置：第 11 块
- 原文摘录："因为相同的东西在它自己看来可能非常不完满，但作为全宇宙的一部分却显得非常完满。"

## 八、本质区别与能力依附类

### F29 可分离性判据（本质区别法）
- 结构：若我能清楚理解 A 而不牵连 B → 则 A 与 B 可分（至少凭至上能力分开）→ 本质不同。用"能否独立被清晰理解"判定两物是否同一本质。
- 适用场景：判断两个事物/概念是否本质不同（如 soul vs body）。
- 原文位置：第 12 块
- 原文摘录："如果我能清楚地理解一个东西，而不牵连到其他东西，那么就足以确定一个东西和另一个不同。"

### F30 能力依附载体分析法
- 结构：某能力（想象、感觉…）若离开某载体就不能被构想 → 必依附该载体（物体性东西）。结构：能力 → 能否脱离载体被理解 → 不能则依附某实体。
- 适用场景：分析"某功能必须寄生在什么之上"。
- 原文位置：第 12 块
- 原文摘录："在它们形式的概念里，包含一些智力作用，由此我推断出它们跟我是有区别的，就像模型是来自一个东西。"

## 九、自然、感官信号与异常解释类

### F31 自然教导 vs 轻率判断二分法
- 结构：区分两类"我以为自然教我的"——①自然真正教给我的（疼痛警示等，真实有用）；②由我自己习惯性的轻率判断塞进心里的（常含错误）。
- 适用场景：区分"客观信号"与"我自己脑补的结论"。
- 原文位置：第 13 块
- 原文摘录："有许多其他的东西好像也是自然教给我的，而我没有真正地从它那里接收到，而是由于在我的精神里一种我对事情做出轻率判断的习惯把它们带到我心里的。"

### F32 感官功能定位法（警示而非告知本质）
- 结构：感官知觉被置于我内，仅为了"警示精神什么对整体有益/有害"，不是用来直接判定外部物体本质。结构：感官信号 → 只是警报 → 不据此推断物体本质。
- 适用场景：正确解读直觉/身体信号；避免从"感觉"直接跳到"事物本质"。
- 原文位置：第 13 块
- 原文摘录："这些感官的知觉通过自然被放在我里面仅仅是为了警示我的精神，什么东西对总和体有什么好处或者坏处。"

### F33 机器类比解释异常法
- 结构：用"钟表走不准但仍遵循自然法则"类比"病人身体出错仍遵循自然法则"，解释"为何完满的制造者会造出会出错的存在"——部分出错 ≠ 整体设计恶意。
- 适用场景：为"系统性缺陷/异常"做非恶意归因；用熟悉机械类比说明复杂系统。
- 原文位置：第 13 块
- 原文摘录："就像一个由齿轮和钟摆组成的钟表一样，当它做得不好，不能完全满足制作者的愿望显示正确的时间时，它也是遵循了自然的法则的。"

## 十、证明与呈现方法类（含后世学者归纳）

### F34 分析法 vs 综合法（两种证明/呈现法）
- 结构：①分析法——从原因到结果，展现"发现过程"，读者像自己发现，适合深思者；②综合法——从结果到原因，用一长串定义/假设/定理强迫读者赞同，适合敌意/不留神者。
- 适用场景：选择论证方式、教学/写作/汇报结构。
- 原文位置：第 14 块
- 原文摘录："分析法展现了一种系统地发现并导出事物的真实方法，就像它是从原因到结果……相反，综合法运用了相反的程序……从结果找到原因。"

### F35 证明顺序安排规则
- 结构：材料按"被理解的顺序"排——最先提出的无需其他推论即被理解，其余仅由前置之物证明。结构：自明项在前 → 后续只依赖前置。
- 适用场景：组织论证/教材/文档的逻辑顺序。
- 原文位置：第 14 块
- 原文摘录："这种规则仅仅包含在首先提出的那些事情，那些不需要随后而来的什么帮助就知道的事情，并且安排所有其他的事情，以便它们的证据仅仅依靠在它们之前的东西中。"

### F36 推理两形式法（直接推论 / 归纳列举）
- 结构：笛卡尔"推理"含两种——①最简单：直接洞悉两命题真假关系（直接推论）；②复杂：从一连串命题得结论，叫归纳法/列举法。
- 适用场景：区分简单推理与多步归纳；设计解释/论证。
- 原文位置：第 15 块
- 原文摘录："在它最简单的形式里，推理是一个被叫作直接推论或者洞悉两个命题真实价值之间的关系的例子……从一连串不连续的命题中得出'结论'的活动被笛卡尔称作归纳法或列举法。"

### F37 现象解释三阶段法（以磁力为例）
- 结构：①收集关于该现象一切有用的经验信息；②推理出"简单性质的组合足以产生该现象的全部"；③确认已穷尽可做的探索。
- 适用场景：科学/工程现象的解释与归因；构建假设。
- 原文位置：第 15 块
- 原文摘录："第一步：假设关于磁力我们所知道的都是从简单的性质里得到的，调查者首先应该收集我们从经验中得到的关于磁石的所有的有用信息。第二步：接下来他将会'推理'出，简单性质的认识的组合足以产生凭经验知道的有关磁力的全部内容。"

### F38 完美 vs 不完美问题界定法
- 结构：完美问题——其解完全由已确知之物决定（多属算术/几何）；不完美问题——需主动限定所考虑的信息，把模糊问题转化为明确的（暂定）答案。
- 适用场景：界定问题可解性；把开放问题收敛为可处理问题。
- 原文位置：第 15 块
- 原文摘录："一个完美的问题是这样的，它的解决方案取决于已经被确知的东西……这种类型的问题'大多是抽象的并且几乎仅仅出现在算术和几何学中'……笛卡尔建议可以通过限定得出解决方案的信息，并有可能将模糊的问题转化为明确的（或者更容易处理的）状态。"

### F39 分析三类型法（代数 / 拆开 / 假设演绎）
- 结构：布克达克区分的三种分析——(a) 含未知数的代数运算（列方程解未知）；(b) 对复杂现象字面/隐喻地"拆开"；(c) 帕皮安假设—演绎（"假设待证者已知"向后找前提）。
- 适用场景：问题求解建模时选分析范式。
- 原文位置：第 16 块
- 原文摘录："(a)分析作为一种有未知数的代数运算的方法……(b)分析是对实际物理或几何复杂现象字面或隐喻的'拆开'；(c)帕皮安的假设—演绎过程，'将要被证明的假设成它是已知的'。"

### F40 广义分析四步法（结构分析范式）
- 结构：①把复杂现象拆成不同成分做"分析"；②实验/观测发现成分间相互关系；③对一切相似情况归纳概括这些关系；④将概括推广到其他情况（综合=重组回复杂情形）。
- 适用场景：一般科学研究/复杂系统分析的方法论骨架。
- 原文位置：第 16 块
- 原文摘录："将一个复杂的现象拆成不同的成分进行'分析'→实验或观测发现不同的成分之间的相互关系→对所有相似的情况，归纳概括这些相互关系→将概括的推理应用推广到其他情况。"

### F41 结构分析 vs 证明分析范式
- 结构：分析的本质是"研究已知与未知因素之间的函数/相互依赖关系"（结构分析），而非仅"证明步骤的分析"。把方法理解为"找变量间关系"而非"推导链条"。
- 适用场景：用"关系/函数"视角重构任何探究方法。
- 原文位置：第 17 块
- 原文摘录："分析的概念是对结构进行分析，而不是对证明进行分析，换句话说，分析就是系统地研究已知和未知因素之间的函数关系。"

### F42 完美问题三条件法
- 结构：任一可解问题须满足——①必有未知之物（否则探索无意义）；②未知须以某种方式被指定（否则找不到它）；③只能根据已知事物去指定未知。
- 适用场景：界定/检验一个问题是否"提得对"；把含糊问题改写成可解问题。
- 原文位置：第 18 块
- 原文摘录："第一，在任何的问题中，必须有未知的东西，否则这将是毫无意义的探索；第二，这个未知的东西，必须以某种方式被指定，否则将不会引导我们发现它而不是其他任何东西；第三，它只能根据众所周知的其他事物去指定。"

### F43 不完善 → 完善问题归约法
- 结构：所有"不完善问题"（含未定未知）都可被简化为"完善问题"。结构：含糊问题 → 显式补齐未知与已知约束 → 转化为完善问题。
- 适用场景：把模糊需求/问题转化为可处理形式。
- 原文位置：第 18 块
- 原文摘录："笛卡尔的程序，包括显示'所有不完善的问题可以简化到完善的'。"

### F44 已知—未知函数比较法
- 结构：认识的每个术语不能孤立获得，只能通过"比较两个或更多对象间的相互关系"获得；方法即把未知与已知联系起来比较。
- 适用场景：概念澄清、关系建模；用"比较"替代"孤立定义"。
- 原文位置：第 18 块（亦见第 19 块）
- 原文摘录："认识的每一个术语都不能凭直觉从一个孤立的单个物体中获得，而是通过比较两个或更多的物体之间的相互关系而获得。"

### F45 方程建模法（方法论典范）
- 结构：设解决方案已生效 → 给所有相关因素（已知+未知）命名 → 不区分地以最自然方式表达关系 → 直到找到同一量的两种表达构成方程 → 解方程。
- 适用场景：把任意问题形式化为可解模型（数学/逻辑建模通用套路）。
- 原文位置：第 19 块
- 原文摘录："我们首先假设解决方案已经生效，并给所有看起来对解释必要的因素命名……然后，不区分已知和未知的数，我们必须以任何最自然地说明这两个未知数之间关系的方式解决困难，直到我们发现可能有两种方式表达一个单一的量。这将构成方程。"

## 十一、论证结构与辩证法类

### F46 矛盾检测分析证明法
- 结构：提出"不能怀疑的 A" → 在思维中既肯定 A 又肯定非 B → 发现矛盾（不能同时成立）→ 推出 A 必与 B 联系。可反复套用（被说服→存在、被骗→存在、存在↔思维）。
- 适用场景：证明两概念必然联系；概念分析中的"归谬"。
- 原文位置：第 21 块
- 原文摘录："通过找到这两个想法之间的矛盾（即他不能在思维中肯定他被说服了而他却不存在），由此他得到结论，他最初的想法必然与对第二种想法的否定联系在一起。"

### F47 综合法三段论结构法
- 结构：大前提（凡思考者皆存在）→ 小前提（我在思考）→ 结论（我存在）。把分析得到的联系铸成标准三段论用于"阐述/教授"。
- 适用场景：把洞察整理成可传授的论证；教学化表达。
- 原文位置：第 21 块
- 原文摘录："凡是在思考的东西都存在 / 我在思考 / 所以，我不存在（矛盾）→ 故'我思，我存在'。"

### F48 作品方法论分类框架（综合 vs 分析文本特征对比）
- 结构：科里给出的可操作区分——综合特征=重要概念有正式定义 + 永恒真理有明确框架 + 无人称 + 只给结论不含失败开始；分析特征=通过例子而非定义引入概念 + 第一人称 + 保留全部推理链（含不成功起点、启发式）。
- 适用场景：判别一篇论证/教材用的是"分析"还是"综合"；写作风格选择。
- 原文位置：第 22 块
- 原文摘录："综合的作品与运用分析的区分开来：'重要概念的正式定义'和'永恒真理迅速明确的识别'的框架……在《沉思集》的关键概念中，像清晰和特异性，被通过实例而不是定义介绍。"

### F49 辩证法·猜想—反驳—修改循环法
- 结构：①以猜想（常是常识命题）开始；②考虑可能反对它的理由；③按反驳修改猜想；④无期限重复直到再也找不出反驳。最初猜想可能是"错误起点"，但其部分真理会保留到最后。
- 适用场景：概念澄清、理论迭代、任何需要逐步逼近真理的探究。
- 原文位置：第 24 块
- 原文摘录："以一个猜想开始的基本的柏拉图哲学的程序，先考虑可能会反对这个猜想的，然后以反驳所建议的任何方式来修改这个猜想……可能无期限地重复，直到调查者得到了一个他/她再也找不出反驳的结果。"

### F50 哲学前概念真谬筛选澄清法
- 结构：对每个概念（肉体/灵魂/精神/思维/观念/实体/上帝）——①从普通语言/前概念出发；②拆分其中"真成分"与"谬误成分"；③保留真成分；④引入更精确术语替换被误解的词。
- 适用场景：概念重构、术语纠偏；把模糊常识提纯为清晰定义。
- 原文位置：第 24 块
- 原文摘录："提出我们对肉体的清晰观点的过程是一个逐渐的过程……在我们对肉体的哲学思考前的概念中挑选出哪些该被保留，哪些不应该被保留，探索那些被保留下来的因素所暗示的东西。"

### F51 属性列表 → 通用原则概念界定法
- 结构：列举某概念属性（易列不全）→ 发现属性间必然联系 → 跳到一条涵盖所有的通用公式（如"上帝=至上完满存在"）。用统一原则决定属性取舍。
- 适用场景：界定复杂/无限属性概念；从枚举收敛到本质。
- 原文位置：第 24 块（深化于第 5、25 块）
- 原文摘录："一旦他做出了大胆的声明，即他有上帝最清晰独特的观念，那么他就会从列出特定属性的清单跳到涵盖所有这些属性的通用公式。他已经将这些完善的部分包含到他的上帝的观念中，因为从根本上说，这个观念是一个至上完满的、无限存在的观念。"

### F52 概念渐进澄清法（跨沉思迭代）
- 结构：某概念（如上帝）的清晰观念不是一次得到，而是经多个阶段逐步加属性、去矛盾、直至"不能设想其不存在"才完成。结构：初引入 → 加属性 → 检矛盾 → 达清晰。
- 适用场景：对困难概念的长期澄清规划。
- 原文位置：第 25 块
- 原文摘录："在前三个沉思的过程中，笛卡尔已经逐渐澄清了他最初的上帝的概念。"

### F53 实体—样式比喻法
- 结构：实体（持续存在者）如同"穿衣服的人"，样式（可变属性）如同"衣服/帽子"；严格说只见样式，却可推断实体存在。用熟悉比喻 bridge 抽象关系。
- 适用场景：用具体比喻讲清"载体 vs 可变属性"。
- 原文位置：第 25 块
- 原文摘录："实体的模式就像我'看到'的在大街上经过的人们穿的衣服，戴的帽子；实体本身就像穿着那些衣服的人。"

### F54 两难推理归谬法
- 结构：把问题设为二难——A 成立或 ¬A 成立；分别推演两支 → 发现两支都导向同一结论 → 故该结论必真。
- 适用场景：逼出"无论如何都成立"的论断；回应两类不同对手。
- 原文位置：第 26 块
- 原文摘录："确定性要么肯定依赖于上帝，要么不依靠他的存在就可得到。如果是第一种情况，那么上帝存在……如果是后一种情况……因此，在这两种情况中都必须承认上帝存在。"

### F55 已知类比说服框架
- 结构：要说服持某标准（如数学证明标准）的对象接受新命题，把新命题"同化"到对方已承认的标准上（本体论证明 ≈ 数学证明），用对方认可的标准倒逼其接受。
- 适用场景：跨立场说服；用对方已有的标准作为桥。
- 原文位置：第 27 块
- 原文摘录："本体论证明同化到了数学证明中：如果一个人赞同后者的结论，就必须同意结论的先验证明，因为它们真实性的基础是相同的；在这两种情况下，它们仅仅用清晰和区别表现自己以确保这些证据是健全的。"

### F56 双受众论证设计法
- 结构：同一论证需同时服务两类受众——①特定对手（如无神论几何学家，用其自身标准反驳）；②广泛中性读者（准备接受复杂路线）。分别设计切入点。
- 适用场景：写作/辩论中针对不同读者分层设计论证。
- 原文位置：第 28 块
- 原文摘录："通过他的反驳，他还会对更广泛的观众演讲——他的读者……后者因为它的多样性是中性的并且因此被准备来支持笛卡尔所遵循的复杂路线。"
