# 《第一哲学沉思集》候选术语提取

> 提取标准：笛卡尔自己造的词，或被他赋予特殊含义的常见词；该词在文中的意思与日常用法不同，且作者明确下过定义或反复专门使用。
> 来源：28 个文本块（block_01～block_28），其中 block_01～13 为正文六个沉思，block_14～28 为分析论文。
> 文件名后缀：`(clara/distincta)` 等括号为该词的拉丁/法文原词。

---

## 术语清单

### 1. 客观实在性（realitas objectiva）
- **作者的定义**：观念通过"表象"所分享到的存在与完满性的程度。"给我表象实体的那些观念……本身包含更多客观实在性（也就是说，通过表象分享更大程度上的存在和完满性）。"
- **跟日常用法的区别**：日常"实在性/真实性"泛指事物是否真实；笛卡尔把它变成一个技术标准，专指**观念作为表象**所承载的"存在量"，与"形式实在性"相对，用来推导观念必有相应原因。
- **原文位置**：block_04（第三段沉思）；进一步论证见 block_05
- **原文摘录**："给我表象实体的那些观念比仅仅给我表象形式的观念多一些东西，并且本身包含更多客观实在性（也就是说，通过表象分享更大程度上的存在和完满性）。"

### 2. 形式实在性 / 现实的实在性（realitas formalis）；卓越地包含（eminenter）
- **作者的定义**：事物**本身实际地**拥有实在性的方式；原因中"形式地或者显著地（卓越地）"包含结果里的实在性。"不仅没有什么可以从无中产生，而且更完满的东西……也不能从不完满中产生。"
- **跟日常用法的区别**：日常"形式"指外在形态；笛卡尔把它与"客观"对照，作为实在性的两种模态——观念里是"客观"的，事物本身里是"形式/现实"的，并加"卓越地包含"表示更高方式地包含。
- **原文位置**：block_05
- **原文摘录**："在动力的、总的原因里，一定至少比在结果里有更多的实在性……它必须拥有同样的东西或者其他比存在于石头中的更卓越的东西。"

### 3. 观念（idea）
- **作者的定义**：思维中"事物的影像"那一类，即"有些是事物的影像，只有这些适合'观念'这个词"。后又被用作一切思维活动都涉及的东西（感知、怀疑、判断中"把某些东西理解为思维主体"）。
- **跟日常用法的区别**：日常"观念"约等于想法、看法；笛卡尔把它从"神圣精神的形式"（中世纪用法）窄化为**人心中的思维内容/表象**，并把观念、意志、情感、判断区分开，且用"客观实在性"衡量观念。
- **原文位置**：block_04（正式定义）；block_25（论文指出这是笛卡尔的翻新用法）
- **原文摘录**："在我的各种思维中，有些是事物的影像，只有这些适合'观念'这个词。比如说我想起来一个人或者一个妖怪、天空、天使，或者（甚至）是上帝。"

### 4. 实体（substantia）
- **作者的定义**："一个可以通过本身存在的东西"（res quae per se ipsam existit）。与"样式"相对，实体是承载各种可变样式的基底。
- **跟日常用法的区别**：日常"实体"泛指实际存在的东西；笛卡尔把它收窄为**只依赖自身而存在**者（上帝是绝对实体，心与物是相对实体），并把实体与样式严格区分。
- **原文位置**：block_25（论文点明此为笛卡尔在第三沉思的定义）；block_04 已用"实体"一词
- **原文摘录**："笛卡尔在第三个沉思的中途非正式地将它定义为一个可以通过本身存在的东西。"

### 5. 样式 / 模式（modus）
- **作者的定义**：实体呈现出来的可变"方式/方法"——如蜡的味道、颜色、硬度、冷热等，是依附于实体的"衣服"。
- **跟日常用法的区别**：日常"样式/模式"指式样、模板；笛卡尔把它技术化为**实体的偶性/变体**（mode），明确说"实体的模式就像我看到的在大街上经过的人们穿的衣服"。
- **原文位置**：block_25
- **原文摘录**："实体的模式就像我'看到'的在大街上经过的人们穿的衣服，戴的帽子；实体本身就像穿着那些衣服的人。"

### 6. 自然的光（lumen naturale）
- **作者的定义**：理性本身直观真理的能力，"自然的光让我看到的是真的"，且它"清晰地展现给我们创造和保持的区别只是推理的区别"。与"自然的倾向"严格区分。
- **跟日常用法的区别**：日常"自然之光"是比喻；笛卡尔把它当成一种**确定的认知官能**，凡它直接显示的必真，并借以区别于易错的习惯/倾向。
- **原文位置**：block_04、block_05
- **原文摘录**："我不怀疑是自然的光让我看到的是真的，比如它已经让我看到的，我来自我怀疑这个事实。"

### 7. 清晰 与 明白/独特（clara / distincta）
- **作者的定义**：真理标准。"我所清楚感知到的都是正确的"（第一总则）；"有一个事物清晰、独特的观念，就是要了解成为那个或那类事物所涉及和不涉及的内容"——即清楚（clara）是当下分明地呈现，明白/独特（distincta）是与一切其他事物分得开。
- **跟日常用法的区别**：日常"清楚/明白"指易懂、不含糊；笛卡尔把它上升为**衡量认知是否为真的客观规范**，并作为上帝存在、外部世界存在的判定门槛（"清楚明显地领会到的"才算真）。
- **原文位置**：block_03（第一总则）；block_09；block_25（论文给出"清晰独特"的释义）
- **原文摘录**："我所清楚感知到的都是正确的。"

### 8. 分析（法）（analysis / resolutio）
- **作者的定义**："分析法展现了一种系统地发现并导出事物的真实方法，就像它是从原因到结果……如果读者想要用这种方法去充分了解所有的事情，他会发现这个方法堪称完美，并使他感觉好像是他自己发现了一些东西。"
- **跟日常用法的区别**：日常"分析"泛指拆解研究；笛卡尔把它界定为一种**特定证明/教学法**——按发现顺序、从结果回溯原因、逐步清除偏见、令读者自得结论。他自称《沉思集》"仅仅用到了分析法"。
- **原文位置**：block_14（对第二组反驳的答辩）；论文讨论见 block_17、block_20、block_24
- **原文摘录**："分析法展现了一种系统地发现并导出事物的真实方法，就像它是从原因到结果。"

### 9. 综合（法）（synthesis / compositio）
- **作者的定义**："综合法运用了相反的程序，使用这种方法的人会感觉是从结果找到原因……运用了一长串定义、假设、定理、原理和问题，以致如果得到的结论中有一个被否定，那么它可能马上就被证明包含了某些已经不存在的东西。"
- **跟日常用法的区别**：日常"综合"泛指汇总；笛卡尔把它界定为与分析相对的**证明/教学法**——用定义、公理、定理链条自上而下推演，能强迫读者（甚至怀有敌意者）接受结论。
- **原文位置**：block_14
- **原文摘录**："综合法运用了相反的程序，使用这种方法的人会感觉是从结果找到原因。"

### 10. 直觉（intuitus）
- **作者的定义**：精神不借想象、直接、当下把握对象的能力——"对它的感觉……从来不是这些（看、摸、想象），但那仅仅是精神的一种直觉"；论文中"直觉是经验的一种"，与推理并列为知识的两来源。
- **跟日常用法的区别**：日常"直觉"指不经推理的直接感觉/预感；笛卡尔把它理性化为**无误的理智直观**（"科学知识仅仅是从直觉和推理中获得"），是清楚明白知觉的范例。
- **原文位置**：block_03（蜡的"精神直觉"）；block_15（论文将直觉作为知识来源）
- **原文摘录**："但那仅仅是精神的一种直觉，这可能是像以前那样不完整的、模糊的，或者是像现在这样清楚明显的。"

### 11. 推理（deductio / 推理）
- **作者的定义**：从已直觉到的前提推出结论的"一切推理过程"——包含直接推论、归纳/列举、类比、假设—推演、解释等。"推理这个词汇涉及所有的推理过程，通过这个过程我们从那些可靠的证明结论的任何论据中验证可信度。"
- **跟日常用法的区别**：日常"推理"约等于逻辑推导；笛卡尔把它**极度拓宽**，纳入归纳、类比、假设、列举等所有"从可靠前提验证结论"的过程，并与"证明"混用（"证明"既可表解释也可表确认）。
- **原文位置**：block_15、block_16（克拉克论文专论此词）
- **原文摘录**："推理这个词汇涉及所有的推理过程，通过这个过程我们从那些可靠的证明结论的任何论据中验证可信度。"

### 12. 天赋观念 / 与生俱来的观念（ideae innatae）
- **作者的定义**：不是来自感官、也不是虚构，而是"与生俱来的"观念，如同工匠印在作品上的记号。"它是我与生俱来的，就像关于我自己的观念是我与生俱来的。"
- **跟日常用法的区别**：日常谈"天赋"多指才能；笛卡尔把它技术化为**观念的来源分类之一**（与生俱来 / 外来 / 人造），并用它解释"上帝""自我"等观念的非经验来源。
- **原文位置**：block_04（三类划分）；block_06
- **原文摘录**："至于观念，如果我们仅仅考虑它们本身……一些似乎是与生俱来的，一些是偶然的，其他的由自身形成（或创造）。"

### 13. 大骗子 / 精怪 / 邪恶的天才（genium aliquod malignum）
- **作者的定义**：笛卡尔为彻底怀疑而**虚构**的一个全能欺骗者——"有一个精怪……它的欺骗手段不亚于上帝的力量，它用全部的精力欺骗我"；后又称"非常强大的、恶毒的天才"。
- **跟日常用法的区别**：这不是日常词汇的延伸，而是笛卡尔**自造的怀疑装置**（思想实验中的角色），用以替代"上帝会骗我"的假设，把一切外部事物视为骗局。
- **原文位置**：block_01（精怪）；block_02、block_03（恶毒的天才）
- **原文摘录**："我要假设有一个精怪，它不同于至上的真理源泉——上帝，它的欺骗手段不亚于上帝的力量，它用全部的精力欺骗我。"

### 14. 我思（我存在）（ego cogito / sum）
- **作者的定义**："我思（有我），我存在。当我宣布它或者在心里想到它的时候，它必然是真实无误的。" 是怀疑无法动摇的第一确定性。
- **跟日常用法的区别**：日常"我思考故我在"常被当作普通格言；笛卡尔把它确立为**不可怀疑的第一原理/起点**，且强调"只在思考时"存在，是分析法的出发点。
- **原文位置**：block_02
- **原文摘录**："我思（有我），我存在。当我宣布它或者在心里想到它的时候，它必然是真实无误的。"

### 15. 意志 / 自由意志（voluntas / liberum arbitrium）；漠不关心（indifferentia）
- **作者的定义**：心中"选择做或不做一件事"的能力；关键翻新——"漠不关心（对两边无所谓）是最低限度的自由，并且它表明了知识的缺乏而不是一种意志的完满性"，越清楚看到善/真，选择越自由。
- **跟日常用法的区别**：日常把"自由"理解为"可任意选两边（漠不关心）"；笛卡尔**反转**它：漠不关心是自由的最低程度，真正的自由来自清楚明白地趋向善。
- **原文位置**：block_07、block_08（第四个沉思）
- **原文摘录**："当我不是因为缺乏理由而倾向于一边而不是另一边时，我感到这种漠不关心是最低限度的自由，并且它表明了知识的缺乏而不是一种意志的完满性。"

### 16. 错误（作为缺陷 / privatio）（error）
- **作者的定义**："这种不正确地使用自由意志的缺陷构成了错误的形式"；错误"不是一个依靠上帝的真实的东西，而仅仅是一个错误……缺陷"，源于意志越出理解范围。
- **跟日常用法的区别**：日常"错误"指与事实不符的判断；笛卡尔把它** ontological 化**为"缺陷/缺乏"（privation）——本身不是实存物，只是完满性的缺失，故不归咎于上帝。
- **原文位置**：block_07、block_08（第四个沉思）
- **原文摘录**："这种不正确地使用自由意志的缺陷构成了错误的形式。"

### 17. 完满性（perfectio）
- **作者的定义**：上帝及一切正向属性的总称——无限、永恒、不变、独立、全知、全能等；"所有我清楚确定为真实和正确的，以及传达出完满性的，都完全包含在这个观念里了。"
- **跟日常用法的区别**：日常"完满"指没有缺陷的状态；笛卡尔把它当作**实在性等级的量度**（越完满=越多实在性），并据以推导上帝必存在、观念必有完满原因。
- **原文位置**：block_05、block_06（第三沉思）
- **原文摘录**："所有我清楚确定为真实和正确的，以及传达出完满性的，都完全包含在这个观念里了。"

### 18. 列举法 / 归纳法（enumeratio / inductio）
- **作者的定义**：推理的一种形式——"从一连串不连续的命题中得出'结论'的活动被笛卡尔称作归纳法或列举法"；也指把相关经验"充分列举"后再推得本质。
- **跟日常用法的区别**：日常"归纳"指由样本概括规律；笛卡尔把"列举"**扩用**为所有"按阶段排列相关证据、从一连串可靠步骤验证结论"的推理论证（含类比、假设），即推理的第二形式。
- **原文位置**：block_15、block_16（克拉克论文）
- **原文摘录**："从一连串不连续的命题中得出'结论'的活动被笛卡尔称作归纳法或列举法（'我们给定或推导的一列名字'）。"

### 19. 简单性质（naturae simplices）
- **作者的定义**：可经验、可直观把握的**最基本构成要素**——如研究磁力时"关于磁力我们所知道的都是从简单的性质里得到的"，调查者先收集简单性质再组合推演。
- **跟日常用法的区别**：日常"简单性质"泛指事物简单属性；笛卡尔把它作为**方法论原子**——所有复杂现象须还原/组合到简单性质才能被理性处理（规则十二、十三）。
- **原文位置**：block_15、block_16
- **原文摘录**："假设关于磁力我们所知道的都是从简单的性质里得到的，调查者首先应该收集我们从经验中得到的关于磁石的所有的有用信息。"

### 20. 完满原则（principium perfectionis）
- **作者的定义**：论文中归为笛卡尔的方法论内核——"笛卡尔坚持的所谓的'完满原则'"，即把科学真理视为概念性/先天真理、以直观把握基本相互依赖关系的原则。
- **跟日常用法的区别**：日常无此固定术语；这是笛卡尔**概念分析特征**的概括——他假定基本前提（如完满性）是直观自明的，科学由其演绎。论文点明这是他区别于亚里士多德式经验科学之处。
- **原文位置**：block_18（欣蒂卡论文）
- **原文摘录**："笛卡尔分析的典型特征作为一种概念分析值得进一步评论……这一特点更容易辨别表现在笛卡尔坚持的所谓的'完满原则'上。"

### 21. 辩证法（笛卡尔式）（dialectica）
- **作者的定义**：论文用以刻画笛卡尔分析法特征——"以一个猜想开始……先考虑可能会反对这个猜想的，然后以反驳所建议的任何方式来修改这个猜想"，即"猜想—反驳—修改"的循环。
- **跟日常用法的区别**：苏格拉底/黑格尔的"辩证法"是概念对立统一；此处论文用"辩证法"专指**笛卡尔分析法中的试探—反驳—修正程序**（如第一沉思先假设再推翻）。
- **原文位置**：block_24、block_25（科里论文）
- **原文摘录**："通过辩证的方法，我的意思是以一个猜想开始的基本的柏拉图哲学的程序，先考虑可能会反对这个猜想的，然后以反驳所建议的任何方式来修改这个猜想。"

### 22. 比较（作为功能关系）（comparatio）
- **作者的定义**：笛卡尔表达"认识"本质的用词——"认识的每一个术语都不能凭直觉从一个孤立的单个物体中获得，而是通过比较两个或更多的物体之间的相互关系而获得"。
- **跟日常用法的区别**：日常"比较"是普通思维动作；笛卡尔把它提升为**方法论核心**——认识 = 把握已知与未知之间的函数/相互关系，是他"结构分析"的代称。
- **原文位置**：block_18（欣蒂卡论文引 AT X,440）
- **原文摘录**："认识的每一个术语都不能凭直觉从一个孤立的单个物体中获得，而是通过比较两个或更多的物体之间的相互关系而获得。"

### 23. 自然 / 本性（natura，广义与狭义）
- **作者的定义**：笛卡尔在两个意义上使用"自然"——广义："上帝本身或者上帝在各种创造物里建立的秩序和部署"；狭义（"我独有的本性"）："上帝给我的所有东西的混合"。并区分"自然教给我的"中哪些是真、哪些是草率判断的习惯。
- **跟日常用法的区别**：日常"自然"常泛指自然界或天然状态；笛卡尔**刻意二分**——作为上帝秩序的"自然" vs 作为"我之构成"的"本性"，并以此解释感觉、欲望、错误来源。
- **原文位置**：block_12（第六沉思）；block_11、block_13 亦涉及
- **原文摘录**："通过自然，一般来说，我现在理解的不是别的东西，而是上帝本身或者上帝在各种创造物里建立的秩序和部署。至于我独有的本性，我理解它们不是什么其他东西而是上帝给我的所有东西的混合。"
